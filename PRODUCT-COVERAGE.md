## Additional recommendations and product limits

- The Overview aggregates CreditFlow grant and reversal records. It does not reconstruct a Shopify Native Store Credit balance and does not currently attribute actual redemption or expiry totals. Those values are explicitly described as unavailable instead of inferred from issuance.
- Orders evaluated/rewarded, active rules and attention records are operational counts, not causal revenue or retention claims. An incident may appear in more than one attention source.
- The “why CreditFlow” copy describes verified capabilities. There are no competitor statistics, security certification claims or guaranteed-sales claims.
- Shopify plan definitions in the code are intended values only. The Partner Dashboard is the runtime billing source of truth for public plan objects and usage pricing.
- Worker queue fairness and expiry scan pagination have unit coverage, but a dedicated PostgreSQL concurrency test is still needed.
- `CREDITFLOW_SUPPORT_EMAIL`, Shopify/Partner credentials, and Resend sender configuration remain staging environment setup gates. No values belong in source control.
